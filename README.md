# 🔐 Network Scanning with Zenmap | Cybersecurity Project

## 📌 Project Overview

This project demonstrates practical network scanning and host discovery using **Zenmap**, the official graphical user interface (GUI) for Nmap.

The objective of this project was to identify active devices connected to a local network, discover their IP and MAC addresses, determine the number of live hosts, and visualize the network topology.

Through this hands-on exercise, I gained practical experience in network discovery, network scanning, and basic cybersecurity reconnaissance.

## 🎯 Project Objectives

The main objectives of this project were:

- Download and install Zenmap on Windows.
- Identify the computer's local IP address.
- Determine the local LAN subnet.
- Discover live hosts connected to the local network.
- Determine the number of active hosts.
- Identify the IP addresses of discovered hosts.
- Identify the MAC addresses of discovered hosts.
- Generate and export a network topology diagram in PDF format.

## 🛠️ Tools and Technologies Used

## 🚀 Project Implementation – Step by Step

### Step 1: Download and Install Zenmap

I downloaded Zenmap from the official Nmap website:

https://nmap.org/download.html

After downloading the installation file, I ran the setup and followed the installation instructions to install Zenmap on my Windows computer.

### Step 2: Identify the Local IP Address and LAN Subnet

I opened Windows Command Prompt (CMD) and executed the following command:

```bash
ipconfig
```

This command displayed my computer's network configuration, including the local IPv4 address and subnet information.

### Step 3: Perform a Network Scan Using Zenmap

I opened Zenmap and entered my local LAN subnet as the scan target.

I selected **Ping Scan** to discover active devices connected to the network.

Zenmap performed the scan and displayed the devices that were reachable within the subnet.

### Step 4: Identify the Number of Live Hosts

After completing the network scan, I identified:

**4 live hosts (including my own computer).**
